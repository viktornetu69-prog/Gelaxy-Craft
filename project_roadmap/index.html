🎯 Key Idea / Концепция проекта

MMO

Massively Multiplayer Online

Мир для сотен игроков одновременно. ПО (Server) управляет состоянием мира, клиенты подключаются и взаимодействуют.

RTS

Real-Time Strategy

Строительство баз, управление юнитами, ресурсный контроль, тактическое сражение.

RPG

Role-Playing Game

Прокачка характеристик, инвентарь, навыки, экипировка, сюжетные квесты.

P2P

Peer-to-Peer Architecture

Хост — диспетчер, клиенты — симуляторы. Минимальная нагрузка на серверное оборудование.
